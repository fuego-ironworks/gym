Purpose: compute the arithmetic mean of three `(school_mean − check_mean)`
scores. The input means must already come from the exact teacher-forced Pythia
model and tokenizer. This pure slice cannot load models or perform interventions.

## Type sketch

- Values: six mean token log-probabilities in one explicitly supplied scalar
  type; three school/check pairs and one aggregate margin.
- Intended central operation: `three_pair_margin : add → subtract → divide_by_three
  → pair → pair → pair → scalar`. `add`, `subtract`, and `divide_by_three` use the
  same scalar type throughout; no implicit integer-to-float conversion.
- Effects: none in the arithmetic slice. The actual experiment needs loading
  pinned checkpoints, tokenization, neural-network forwards, hooks and durable
  file output; those are effectful operations outside this slice.
- Invariant: swapping school and check in every pair negates the margin if the
  supplied scalar arithmetic has the expected laws. The three pairs each have
  equal weight. Empty continuations and nonfinite input scores are errors to
  reject at the external model boundary, not silently accepted here.
- Backend and primitives: the pure slice needs scalar arithmetic; the whole
  experiment needs a PyTorch-compatible model runtime, hook/activation API,
  checkpoint revision pinning and CPU backend exposed to Idriç. Those interfaces
  are not established in this checkout.
