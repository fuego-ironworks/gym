# BME advice generation and evidence diagnostic

This directory freezes the historical `bme-high-school` prompt and Blackball’s 14 public BME prompts. The literal prompt runs twice with no evidence and twice with the same evidence, using greedy decoding and sampling at temperature 0.7, top-p 0.9 and seed 29 per fixed batch. Each run has a 160-token cap. The raw record retains the prompt, token IDs and stop reason. A goodwill or repetition classifier alone cannot identify the first consequential recommendation. Use brief spans from the raw text to mark the first recommendation and the earliest material debt or employment check. Record no answer, repetition and truncation even when a consequential recommendation appeared first. The evidence packet uses the completed BME award series, the Ohio State study, Michigan cohort recovery, and the BME campaign’s dated employer and stipulated cash examples. A hypothetical offer or cash schedule applies only in its stated example. The 17 authored pairs test preference directly on candidate text. Each candidate follows the same prefix within an item. Record mean and total log probability and the change in each signed margin from the closed-book to the evidence condition. The bare-answer condition measures lexical preference in a short context. In five synthetic twins, the facts reverse the correct action while the question and both candidates stay fixed. Assess whether each twin selects both evidence-warranted continuations. Use the unconditioned and closed-book scores as priors for these pairs. These authored probes measure conditional likelihood. The separate generation record measures what the model told the student.

The protocol uses the final 410M deduplicated model and its pinned tokenizer. The runner accepts a checked local model directory and can run the same inputs on a standard public GitHub runner. Gating for retraining follows the saved plan. If fewer than half of the closed-book greedy prompts produce interpretable advice, run the same inputs with the neutral question-and-answer wrapper. If that still fails, evaluate a distinct larger or instruction-capable baseline before training on bad-advice corrections.
